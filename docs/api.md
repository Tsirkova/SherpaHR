# API существующего приложения

Ответ: `{"data": ...}`; ошибка: `{"error": "описание"}` с соответствующим
HTTP-статусом. JSON UTF-8. Заголовок `X-Demo-User: 1` выбирает Анну,
`2` — Бориса, `3` — Веру. По умолчанию 1. Это открытый демо-переключатель,
не доказательство личности; локальный API не предназначен для публикации в сеть.

| Метод и путь | Текущее поведение |
|---|---|
| `GET /api/health` | Проверка запуска сервиса |
| `GET /api/context` | Демо-пользователи, выбранный пользователь, время UTC и дата создания демо |
| `GET /api/projects` | Только проекты текущего пользователя, участники и количество задач |
| `GET /api/projects/{id}/tasks` | Все задачи доступного проекта |
| `POST /api/projects/{id}/tasks` | Создать задачу в активном проекте |
| `GET /api/tasks/{id}` | Доступная задача с комментариями и авторами |
| `PATCH /api/tasks/{id}` | Изменить поля с проверкой версии |
| `POST /api/tasks/{id}/comments` | Добавить комментарий от текущего пользователя в задачу активного проекта; 201 и комментарий с автором |
| `GET /api/attention` | Сводка «Требует внимания» по активным проектам, где пользователь — руководитель. `?include_hidden=1` добавляет разобранные |
| `POST /api/attention/{taskId}/ack` | Отметить задачу разобранной: скрыть до следующего изменения или комментария. Только руководитель проекта |
| `DELETE /api/attention/{taskId}/ack` | Вернуть разобранную задачу в сводку |

Поля задачи для создания и изменения: `title`, `description`, `status`,
`assignee_id`, `due_at`. При создании `title` обязателен. Неизвестные поля
отклоняются. Исполнитель — участник проекта или `null`. Даты — строго
`YYYY-MM-DDTHH:mm:ssZ` либо `null`; текущий UI редактирует их с точностью до минуты.
Для PATCH обязательно целое поле `version`, полученное при чтении.
Успешное изменение увеличивает версию; устаревшая версия возвращает 409.
Метод добавления комментария принимает только `{"body":"текст"}`; пробелы по краям
обрезаются, пустой текст — 422. Автор — выбранный демо-пользователь.

Сводка внимания (`GET /api/attention`) возвращает `projects` (счётчики по проектам),
`items` (задача, причины `reasons` с `code`/`label`/`severity`, `score`, цитата
`quote`), `hidden_count` и пороги `rules`. Причины: `overdue` (срок прошёл),
`due_soon` (срок в ближайшие 48 ч), `blocked`, `unassigned`, `stale` (задача в работе
или заблокирована без изменений и комментариев 3+ дня) и `waiting_manager` —
в обсуждении есть просьба участника, на которую руководитель ещё не ответил.
Последнее определяется по ключевым словам («помоги», «нужно решение», «ждём»,
«не можем продолжить» и т. п.) и упоминанию имени руководителя. Готовые задачи
и архивные проекты в сводку не входят. Отметка «разобрано» хранится для пары
пользователь–задача и привязана к версии задачи и последнему комментарию:
любое изменение возвращает задачу в сводку. Не руководитель — 403.

Максимумы строк в байтах UTF-8: название 200, описание 10000, комментарий 5000.
Максимум тела изменения — 32 KiB. Ошибка валидации — 422, JSON — 400,
неизвестный пользователь — 401, нет прав руководителя — 403, отсутствующий или недоступный объект — 404,
запись в архив — 409. Поиск и фильтр статуса в текущем UI выполняются локально.
